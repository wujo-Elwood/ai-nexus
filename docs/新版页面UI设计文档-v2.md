## 1. 任务与约束

**用户任务**：在功能不变的前提下，重新设计主界面全部功能页面的视觉语言，要求与现行「深空 HUD」风格完全不同、有眼前一亮的感觉。

**硬约束**：
1. **全局星空背景不变**——`MainLayout.vue` 的 cosmic-background（星空 + 星云 + 流星）原样保留；
2. **登录页不变**——`LoginView.vue`（太阳系背景 + 登录卡）原样保留；
3. 功能、信息架构、路由全部不动，只换视觉表达与交互质感。

**品牌沿用**：产品名「AI 智能平台 / AI Nexus」、 slogan「一个入口，调用全球顶尖模型」不变。

## 2. 现状基线：要告别什么

现行 v1 语言（「深空 HUD」）的识别特征，也是本次要**全部替换**的部分：

## 3. 品类与标杆

**品类**：AI 工作台（RAG 知识库 + 多模型对话 + 文档抽取 + 智能体管理），后台型生产力工具。
**用户来首屏做什么**：看知识库列表、进对话、传文档。首屏必须第一排就是内容对象，页头不超过两行。

**拆标杆**：
- **Linear**（暗色玻璃 + 渐变高光）：暗而不闷靠「玻璃上的光」；动效短促（≤200ms）；导航选中用胶囊。取：玻璃材质、光效克制、胶囊选中态。舍：它的冷灰单色——我们需要和登录页的暖太阳系同世界。
- **Raycast**（玻璃悬浮岛 + 彩色渐变图标）：悬浮岛让背景透出，渐变只用在主动作。取：悬浮岛侧栏、渐变主按钮。舍：命令面板为核心的结构。
- **Vercel Dashboard**（黑白高对比 + tabular 数字）：数字对齐和灰阶纪律。取：数字排版纪律。舍：它的纯平面——我们有星空背景可以联动。

### 差异检验

- **骨架**：A 悬浮岛侧栏 / B 顶部 dock + bento / C 顶部通栏标题 + 无侧栏——三个不同结构。
- **字体**：A 无衬线大标题 / B 超大展示数字 / C 衬线标题——不同。
- **色彩**：A 白玻璃 + 极光渐变 / B 深黑 + 模块光谱多色 / C 墨黑 + 冰蓝单色——不同色相家族与材质感。
- **主视觉**：A 极光光带 / B 行星光环 / C 大字排版本身——不同。
- 四项任意两方向至多一项相同，检验通过。

### 选定：方向 A，理由

1. **背景不变的最优解**：只有 A 让星空透过玻璃持续参与画面；B 用深黑面板遮盖背景，C 更是全面遮盖——两者都让「背景不变」退化成「背景看不见」。
2. **与登录页同世界**：登录页是太阳系 + 玻璃卡片，A 的玻璃材质是它的自然延伸，进站不换世界观。
3. **可执行性**：A 通过替换 CSS 令牌 + Element Plus 变量层即可覆盖全部 17 页；B 需要逐页重新构图，C 需要更换整套字体资产，改造成本与风险都显著更高。
4. **效率**：玻璃半透明面板保持背景可见的同时对比度可控，长列表阅读性优于 B 的高饱和混排。

## 5. 方向 A 设计语言规范

### 5.1 设计原则

1. **玻璃是唯一的材质**：所有面板 = 同一种磨砂玻璃，层级靠透明度与 blur 深浅表达，不引入第二种材质（无描边、无角标、无网格线）。
2. **极光是唯一的彩色**：渐变只出现在三处——主动作按钮、导航选中胶囊、页头极光带。其余一律无彩（白玻璃 + 灰字 + 语义点）。饱和度预算：极光色面积 < 页面 8%。
3. **背景是布景，不是贴纸**：面板间距、留白处必须让星空可见；内容区不做整片底色。
4. **圆角一个尺度系**：面板 18 / 卡片 14 / 控件 10 / 胶囊 999，此外无圆角。

### 5.2 设计令牌

```css
:root {
  /* 玻璃 */
  --glass: rgba(255, 255, 255, 0.055);        /* 一级面板 */
  --glass-2: rgba(255, 255, 255, 0.09);       /* 悬浮层/气泡 */
  --glass-3: rgba(255, 255, 255, 0.13);       /* hover/激活底 */
  --glass-line: rgba(255, 255, 255, 0.12);    /* 玻璃内侧 1px 高光（仅顶部 inset） */
  --glass-sheen: linear-gradient(180deg, rgba(129,140,248,.075), rgba(255,255,255,.008) 34%);
  /* 极光 */
  --aurora-c: #22d3ee;  /* 青 */
  --aurora-i: #818cf8;  /* 靛 */
  --aurora-f: #e879f9;  /* 品红 */
  --aurora: linear-gradient(90deg, #22d3ee, #818cf8 52%, #e879f9);
  --aurora-glow: 0 0 24px rgba(129, 140, 248, 0.25);
  /* 数据可视化：单色系（不占用极光三处纪律） */
  --dataviz: linear-gradient(90deg, #7dd3fc, #0ea5e9);   /* 青系：进度/柱图 */
  --dataviz-hi: linear-gradient(90deg, #a5b4fc, #6366f1); /* 靛系：今日/强调列 */
  /* 文字 */
  --ink-1: #f4f6fb; --ink-2: #9aa3b5; --ink-3: #626b7e;
  /* 语义点（沿用 v1 习惯，换色相） */
  --ok: #34d399; --warn: #fbbf24; --bad: #fb7185; --info: #38bdf8;
  /* 形状与投影 */
  --r-panel: 18px; --r-card: 14px; --r-ctl: 10px; --r-pill: 999px;
  --shadow-float: 0 18px 50px rgba(0, 0, 0, 0.45);
  --shadow-panel: 0 8px 28px rgba(0, 0, 0, 0.28);
  --font-sans: "MiSans", "HarmonyOS Sans SC", "Noto Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
  --font-mono: "JetBrains Mono", Consolas, monospace; /* 仅数据小注 */
  --motion: cubic-bezier(0.32, 0.72, 0.24, 1); /* 220ms 标准时长 */
}
```

### 5.3 组件语法

- **玻璃面板**：`background: var(--glass); backdrop-filter: blur(18px) saturate(140%); border-radius: 18px; box-shadow: var(--shadow-panel), inset 0 1px 0 var(--glass-line);`——顶部 1px 内高光代替描边。
- **悬浮岛侧栏**：宽 224px，距窗口上/左/下各 14px，圆角 20px，`--glass-2` + blur(24px)；窗口四周露出星空。
- **导航项**：高 38px，默认灰字；hover 玻璃提亮；激活 = 极光胶囊（渐变 12% 底 + 渐变文字 + 左侧 6px 光点），胶囊整体带 220ms spring 滑移。
- **主按钮**：极光渐变实底，深字 #0b1020，pill，`box-shadow: 0 6px 20px rgba(99,102,241,.35)`；hover 亮度 1.08，active scale(0.97)。
- **次按钮**：`--glass-2` 玻璃面 + 白字 pill；危险按钮 = 玫红 #fb7185 文字 + 10% 底。
- **输入**：`rgba(255,255,255,0.06)` 底、10px 圆角、无边框；focus 时 `box-shadow: 0 0 0 1.5px rgba(129,140,248,.55), 0 0 18px rgba(34,211,238,.15)`。
- **玻璃卡**（知识库/智能体/文件）：14px 圆角，卡内上方留给「星环」或渐变徽章；hover 上浮 2px + `--glass-3`。
- **数据胶囊**（原读数条）：横排玻璃 pill，数字 32px tabular 白，标签 12px 灰，趋势用 ok/warn 小箭头。
- **状态**：彩点 + 文字（沿用 v1 语法），色相换语义四色；「处理中」呼吸动画保留。
- **表格**：玻璃面板内横线列表，表头 12px `--ink-3`，无竖线，行 hover `--glass-3`。
- **聊天**：用户消息 = 右侧 `--glass-2` 气泡（14px 圆角，右上角 4px）；AI 消息 = 无底直排，左缘 2px 极光渐变竖线 + 渐变光点头像；引用证据 = 可折叠玻璃抽屉卡（默认收起为一行置信度摘要）。
- **弹窗**：`--glass-2` + blur(28px) + 18px 圆角 + `--shadow-float`，遮罩 `rgba(2,3,10,0.6)`。

### 5.4 三处基本动效（与记忆点）

1. **主操作反馈**：点击主按钮 → scale(0.97) 回弹 + 光晕外扩一圈（280ms）；发送消息后输入岛内按钮化作光点汇入消息流（后续实现，静态稿先做回弹）。
2. **状态切换来路**：导航切换时极光胶囊从旧项滑到新项（220ms spring），内容玻璃板交叉淡入。
3. **首次入场**：页面加载 → 玻璃板自下 16px 浮入（320ms）+ 页头极光带自左向右扫光一次（600ms，仅一次，不循环）。
4. **记忆点**：知识库卡「就绪星环」——SVG 环形进度（可问答文件占比），常亮 + 6s 缓慢呼吸；这是全页唯一的常驻动画。

### 5.4.1 评审后收紧的补充规则（2026-10-03 独立评审轮）

- **极光纪律最终版**：三色渐变只允许出现在①主按钮、②导航选中胶囊、③页头极光带。就绪星环、柱状图、进度条等**数据可视化一律用单色系**（青系 `--dataviz` 表常规，靛系 `--dataviz-hi` 表今日/强调）；AI 头像是玻璃小球（非渐变）；智能体卡不加渐变描边，运行状态用状态点表达。
- **首屏必须收口**：任何列表/网格页在主内容下方要有一条「次级内容带」（最近文档 / 最近调用 / Token 明细），高度 160–220px，杜绝页面底部大面积空白星空。
- **聊天回答限宽**：AI 回复正文 max-width 820px；用户气泡右上角 5px 圆角。
- **玻璃质感来源**：所有面板统一 `--glass-sheen` 顶部环境反光 + 上缘 1px 高光（rgba(255,255,255,.16)）；全局滚动条 6px 细条 rgba(255,255,255,.14)。
- **渐变徽章色系**：智能体/文件类型徽章只用极光家族色相（青/天蓝/靛/紫/品红）+ 中性玻璃灰，不引入绿/橙等第四族色相。
