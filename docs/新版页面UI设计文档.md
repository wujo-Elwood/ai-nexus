## 1. 设计任务

**用户是谁、来做什么**：企业内部的知识与数据工作者。高频动作按序：① 在知识库问答并核对引用；② 管理知识库与文件（上传/重试/清理）；③ 看智能体执行了什么（步骤回放）；④ 看统计与健康。

**首屏主角**：这是内容型工具页面（非说服型页面），每个页面的首屏就是**第一排真实内容本身**——知识库页首屏是第一行知识库条目，聊天页首屏是最后一条问答。页头只占一到两行，不放口号、不放解释段落。

**设备**：桌面 1200–2560px，`min-width: 1200px` 已锁定，无移动端。

## 2. 品类与标杆拆解

**品类**：企业 AI 知识/数据工作台（RAG 问答 + 多智能体 + 数据治理）。

**拆标杆一：Linear**（项目管理工具，风格最鲜明的现代企业工具）

| 要素 | 它是什么样 | 为什么 | 本产品取舍 |
| --- | --- | --- | --- |
| 行式列表 | 一切记录都是行，无卡片 | 一屏看 30 条，扫读优先 | **沿用**——知识库/智能体/任务全改行式 |
| 键盘优先 | Ctrl+K 命令面板、快捷键印在界面上 | 高频用户免鼠标 | 暂缓（后续版本），侧边导航保留点击 |
| 中性灰阶 + 单强调色 | 界面几乎无彩，强调色只给状态 | 内容是主角 | 沿用，但强调色换成琥珀（见方向卡） |
| 数字等宽 | 统计/计数用 mono 字体 | 数字对齐可扫读 | **沿用** |
| 悬停才浮现操作 | 行 hover 才出现菜单 | 安静 | **沿用** |
| 直角小圆角 | 4–6px，几乎无阴影 | 仪器感 | 沿用 |

**拆标杆二：Vercel Dashboard**（部署平台，深色企业工具标杆）

| 要素 | 它是什么样 | 为什么 | 本产品取舍 |
| --- | --- | --- | --- |
| 深底暖白字 | 纯黑近底 + 微暖白文字 | 长时间注视不刺眼 | **沿用**（与星空天然契合） |
| 状态 = 彩点 + 文字 | 绿点 Deployed、黄点 Building | 状态扫读零成本 | **沿用**（替换本产品现有 badge 盒） |
| 分割线分层 | 1px 细线分区块，无底色块 | 排版即结构 | **沿用**（核心手法） |
| 事件流 | 部署历史是日志流 | 时间线叙事 | **借鉴**——智能体步骤/任务中心做成日志流 |
| 无装饰 | 界面里没有任何与任务无关的元素 | 专业信任感 | **沿用并加强**：星空是唯一装饰，内容区零装饰 |

**品类基线**（用户已期待、必须保留）：左侧导航、列表页有搜索与主操作按钮、问答流按时间正序、表格有表头。**品类套路（至少打破一个）**：本设计打破"后台 = 卡片网格"这一条——所有记录行式化，内容无容器。**不撞脸检查**：深底 + 琥珀 + 星空 + 日志排版，与 Linear（白/紫）、Vercel（纯黑/白字无星空）均可区分。

## 3. 调性（五刻度，依据来自产品事实）

| 刻度 | 取值 | 依据 |
| --- | --- | --- |
| 能量 | 安静 | 知识工作需要专注；星空背景已提供情绪，内容层必须静 |
| 完成度 | 精致 | 对齐 4px 网格、分割线 1px 统一、字号 6 档封顶 |
| 密度 | 中密 | 企业工具，行高 54px 的行列表；正文 14px（长时间高密度使用允许 13.5px） |
| 分量 | 轻 | 细线、无底色块、无重阴影；唯一"重"的是主按钮 |
| 严肃度 | 庄重 | 企业采购审美；圆角 ≤8px、无插画、动效幅度 ≤200ms |

**模糊词翻译**（本设计使用的词全部可观察）：
- "高级" = 深底上的暖白文字 + 琥珀仪表金数字 + mono 等宽读数，像精密仪器而非 SaaS 模板；
- "克制" = 琥珀色只出现在：主按钮、当前态、关键数字、状态点，合计不超过画面面积 5%；
- "干净" = 内容区零底色块、零阴影、零渐变；分层只靠 1px 线和留白。

## 4. 方向卡：深空任务日志

| 字段 | 内容 |
| --- | --- |
| **北极星** | 用起来像在深空观测站的日志台前工作：舷窗外是星海，舷窗内每一条知识、每一次问答、每一个智能体动作都是一条**打印在仪表介质上的日志条目**——没有盒子，只有记录 |
| **调性** | 见 §3 五刻度 |
| **标杆与取舍** | 见 §2：沿用 Linear 行式/等宽数字/悬停浮现、Vercel 彩点状态/细线分层/日志流；换掉 Linear 的白底紫强调（星空要求深底琥珀）、换掉 Vercel 的纯黑（星空是深蓝黑且带星点） |
| **生成引擎** | **角色原型 + 自有资产 =「贾维斯 HUD 正式化」**：产品 showcase 里本就有「贾维斯 HUD」艺术页——把它那种琥珀线框、角标括号、mono 读数的观测舱仪表语言，从演示页正式化为企业界面。证据：星空背景与琥珀主色已存在，HUD 是它们唯一自洽的完成态。由它推出：面板 = 仪表玻璃（深色半透明 + 1px 琥珀暗线 + 对角角标括号）；系统标签 = mono 大写字距路径（SYS://KNOWLEDGE-BASE）；读数 = 发光的 mono 琥珀数字；日志 = mono 工具行（步骤号 + 工具名 + 耗时 + ✓） |
| **首屏骨架** | 内容页：页头一行（22px 标题 + 右侧主按钮）+ 数字条一行 + 第一排行列表**必须完整出现在首屏**。聊天页首屏 = 最后一条问答完整可见。不使用说服型骨架 |
| **页面结构** | 左侧 216px 平面导航（1px 竖线分隔，无底色）+ 全宽内容区（max-width 1080px 居中）；聊天/智能体对话为左右窗格 |
| **字体** | 界面：Noto Sans SC（400/600/700）；标题同族 600 不用衬线（日志是仪器输出，不是杂志）；数字与 ID：JetBrains Mono（`font-feature-settings:"zero" off` 关斜杠零）；字阶 6 档：12 / 12.5 / 14 / 16 / 20 / 24 |
| **色彩** | 深空底 `#0b0c10`；暖白文字 `#f7f5f2`；次级 `#b7bbc4`；弱化 `#8b90a0`；仪表金 `#e5a044`（读数）/ `#ffc76d`（悬停字）；分割线 `rgba(247,245,242,.1)`；状态：正常 `#7fdfa4`、进行中 `#f4b35a`、异常 `#ff8a8a`。色彩身份 = **深空黑金**，与 Linear 白紫、Vercel 黑白区分 |
| **主视觉** | 星空本身（品牌资产）+ 数字条的琥珀 mono 读数。不新增任何插画 |
| **图标** | 换 **Radix Icons**（15px 网格、直角端点，仪表感，与 JetBrains Mono 同气质）；侧边栏保留 Unicode 字符（▣◇◈，品牌资产）；现有内联 SVG（麦克风/喇叭/大拇指）重绘为 Radix 线宽（1.5px） |
| **控件语法** | 一句话：**细线 + 微亮**。按钮 = 无底色文字钮（hover 琥珀字）/主操作琥珀实底深字；输入框 = 无框，仅底部 1px 线，focus 线变琥珀；行 hover = 微亮 + 左琥珀条；状态 = 彩点 + 文字，无底盒；按下 = 亮度加深，无位移 |
| **动效** | 手感：**仪器指示灯**——变化即时、无弹跳、无位移。三处基本动效：① 主操作反馈：发送后输入条文字清空的同时，新日志条目从输入区方向淡入（150ms）；② 状态切换：文件状态从"解析中"变"可问答"时，彩点颜色过渡 + 一行新日志文字滑入（150ms）；③ 首次进入：页头与第一排内容先后 80ms 淡入（星野已有出场，内容不再另加）。动效记忆点见 §5 聊天页 |
| **结构性突破** | ① **对话页没有消息气泡**：问答以日志条目直排，每条带 mono 标签行（LOG // INPUT · OUTPUT · CITED 2）——把"聊天软件"套路改成"任务日志"；② **每个区块都有系统路径标签**：SYS://KNOWLEDGE-BASE 这类 mono 状态行 + ONLINE 脉冲点，把"页面标题"升级为"观测站控制台读头" |
| **记忆点** | ① **AI 工作时刻**：智能体执行步骤按日志流逐行打印（01 web_search · 612ms ✓），回答从日志里"长"出来；② **仪表读数**：页头 mono 琥珀发光数字条（+涨幅角标），像观测舱仪表；③ **角标括号**：每块面板左上/右下的琥珀对角括号，hover 时边框与光晕同步点亮 |
| **放弃什么** | 放弃：卡片容器、玻璃拟态 blur、渐变、圆角盒（>8px）、阴影、彩色底 badge、衬线标题、首屏口号与解释段落、 emoji 图标 |

## 5. 全局视觉语言

### 5.1 文字角色

| 角色 | 规格 | 用途 |
| --- | --- | --- |
| 页标题 | 20–24px / 600 | 页头 h1 |
| 条目名 | 14px / 600 | 行列表首行 |
| 正文 | 14px / 1.7 | 回答、描述 |
| 辅助 | 12.5px / 1.6 | 时间、来源、占位 |
| 小节标题 | 11px / 600 / 大写 / 字距 .12em / `--text-3` | 侧边栏分组、区块标题 |
| 读数 | JetBrains Mono 600 · 24–26px | 数字条 |
| 行内读数 | JetBrains Mono 13px | 表格数字、ID、耗时 |

中文排版：正文行高 1.7；多行标题 1.3；`text-wrap: pretty` 减孤字；"38 秒""不会"等用 `white-space:nowrap` 包裹。

### 5.2 色彩与表面

全部色值见方向卡。使用铁律：
- 琥珀面积预算 ≤5%：只允许出现在主按钮、当前导航态、数字条读数、行 hover 左条、focus 线；
- 状态 = 彩点 + 语义色文字（无底盒）；异常另加 `⚠` 前缀兜底色盲；
- 内容区唯一允许的"底色"是代码块 `rgba(247,245,242,.04)`；
- 对比度：`--text-1` 16:1、`--text-2` 7.5:1、`--text-3` 4.6:1（仅限辅助信息）；琥珀文字只用于 ≥14px/600。
- 在星空背景上的任何文字，其背后 200px 范围内不得有流星轨迹经过（现有流星层 zIndex 已低于内容，维持）。

### 5.3 线与留白

- 分割线只有一种：`1px rgba(247,245,242,.1)`；粗细不分级（纸面无粗线分版面需求）；
- 分组优先用留白（24/32px），分割线只在行列表与页头下出现；
- 间距基数 4px：行内 8/12，区块 16/24，页 32/40；
- 内容区 max-width 1080px 居中（阅读行长约 70–80 字符）。

### 5.4 控件语法细则

| 控件 | 默认 | 悬停 | 激活/选中 | 禁用 |
| --- | --- | --- | --- | --- |
| 主按钮 | 琥珀实底 + `#16130c` 字 | `#ffc76d` 底 | — | 40% 透明 |
| 次按钮 | 透明底 + 1px rgba 白线 + `--text-2` 字 | 字变暖白、线变亮 | — | 40% 透明 |
| 文字按钮 | `--text-3` | 琥珀 | 琥珀 + 不可再点（如已选大拇指→取消态灰） | — |
| 输入框 | 无框 + 底 1px rgba 白线 | 线亮 | focus 线琥珀 | — |
| 行 | 透明 | 微亮 + 左琥珀条 | 选中行保持左琥珀条 | — |
| 弹窗 | 深色直角窗（继承 EP 深色），标题下 1px 分割线，危险操作红字置左 | | | |

### 5.5 图标

- 迁移到 **Radix Icons**（15px、1.5px 描边、直角端点）；现有 EP 图标与内联 SVG 逐步替换；
- 侧边栏 Unicode 字符（▣◇◈✦❖∑☁）保留——它们是"观测站标识牌"语言，与日志风格同源；
- 能不用就不用：行列表的文件数、时间、状态全用文字，不加图标。

### 5.6 三处基本动效（汇总）

见方向卡动效字段。补充规则：流式回答不做打字机逐字动画（日志感 = 逐行出现，每次一行，80ms）；所有过渡 ≤200ms、曲线 `ease-out`；禁用呼吸灯、光晕、粒子（星空已有，内容层禁止）。

## 6. 页面逐一设计

> 每页标注：首屏主角 / 结构 / 关键状态。所有列表页共享 §2.2 行原语与 §4 控件语法。

### 6.1 App Shell

- 左侧 216px 导航：白字平面列表（无底色块），当前项 = 琥珀字 + 左侧 2px 琥珀条；智能体入口标签动态跟随当前智能体（已实现行为保留）；
- 内容区 1080px 居中；右下角悬浮元素（返回胶囊）改为**文字链接式**：「⟲ 返回 联网搜索智能体」（琥珀下划线链接，去胶囊盒）。入口为**会话级**：本次打开页面期间进入过智能体才显示，刷新/重开页面即消失，10 分钟未再次进入自动消失（记录存页面内存 `stores/agentRecent.js`，与侧边栏动态菜单用的 localStorage `agent-recent` 互不相干）。

### 6.2 登录页 —— 不变

维持现有实现（3D 太阳系 + 玻璃卡）。本设计不覆盖登录页。

### 6.3 知识库列表 `/kb`

- **首屏主角**：第一行知识库条目（页头 + 数字条占两行后必须可见）；
- 页头：`知识库` 20px + 描述一行 + 右侧主按钮「新建知识库」；
- 数字条：`12 知识库 │ 8 可问答 │ 247 文件`；
- 全局向量重建：**进行中时**为页头下一行状态行（琥珀彩点 + 进度百分比 mono + 「查看任务中心」链接）；**完成/空闲时不渲染**；
- 工具行：下划线式搜索框 + 右侧筛选文字链接（全部 / 我创建的 / 共享给我的，当前项琥珀）；
- 行列表：每行 = 首字图标（22px 琥珀 soft 方块）/ 名称（600）+ 描述 / 状态（彩点+文字）/ 元信息（N 个文件 · 创建人 · 更新时间）/ ⋯ 菜单（含共享设置）/ 「去提问」文字链接；
- 空态：居中 13px 灰字「还没有知识库」+ 下划线链接「新建第一个知识库」。

### 6.4 文件管理 `/file/:kbId`

- 面包屑行（知识库名 / 文件）；上传 = 文字按钮「＋ 上传文件」+ 一行支持格式说明；
- 文件行列表：名称（600）/ 类型 / 状态（彩点）/ 大小 mono / 时间 / 操作（重试仅失败行显示）；
- 解析阶段展示：`● 解析中` → `● 视觉识别中`（紫色点 `#c084fc`）→ `● 可问答`。

### 6.5 知识库洞察 `/kb/:id/insights`

策略表单按 §4 控件语法纵排分组（切片 / 检索 / 视觉 三小节，小节标题用 11px 大写灰字）；健康 = 一行读数（mono 大数字 + 状态点）；不做环形仪表。

### 6.6 AI 聊天 `/chat`

- 三窗格：左历史窗格（可折叠）│对话流│；
- **消息 = 日志条目**（方向卡结构性突破）：头像 22px（AI = 琥珀 soft 方块"AI"，你 = 深色方块"你"）+ 名字/时间 12px 灰字头 + 正文直排；用户条目左侧 2px 琥珀条；问答对之间 1px 分割线；
- 引用：回答尾部一行「引用 2 条」文字链接，展开为切片原文（mono 来源标注）；
- 操作行：朗读 / 有帮助 / 无帮助（灰字，hover 琥珀；已选态保持琥珀、再点取消）；
- 追问建议：主色下划线链接横排；
- 失败：红色行内文字 +「重试」链接；
- 输入区：窗格底部固定，无边框 textarea（占位符即说明），右下麦克风 + 「发送 ↵」；
- **记忆点**：流式回答按日志逐行出现（80ms/行），完成时操作行淡入。

### 6.7 智能体管理 `/agents`

行列表：首字图标 / 名称（600）+ 状态 tag（彩点文字）/ 描述 / 技能文字链（mono 12px）/ 元信息（模型 · 场景）/ 「进入 →」文字按钮。按最近使用排序，第一个行尾加「上次使用」琥珀小字。

### 6.8 智能体对话 `/agent-tools`

同 6.6 日志条目规范。**记忆点**：执行步骤 = 日志流——`01 search_city_location · 320ms ✓` 逐行打印（mono 工具名琥珀），全部完成后步骤区收起为一行「执行过程 · 2 步 · 1.2s（展开）」。

### 6.9 技能管理 `/skills`

三小节纵排：智能体绑定（行式：智能体名 + 开关 + 技能文字链 + 编辑）、技能目录（行式：技能名 + 描述 + 启停开关 + 参数文字）、调用统计（表格：横线式，数字 mono）。搜索源配置入口 = 技能行内文字链接。

### 6.10 文档抽取 `/extract`

## 7. 关键状态与边界

| 场景 | 设计 |
| --- | --- |
| 无证据拒答 | 回答区一行灰字「模型未能生成带有效依据的回答…」+「换个问法」链接 |
