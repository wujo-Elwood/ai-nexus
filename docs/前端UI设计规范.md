# AI Nexus 前端 UI 设计规范 v3.0 ——「深空纸面」排版驱动风格

> 版本 v3.0（定稿）· 2026-10-03 · 取代 v1/v2
> 一句话定位：**宇宙星空背景保留，内容层去掉全部卡片容器**——回答、列表、统计直接排在星空上，靠标题层级、留白、分割线组织信息。
> **本规范为提案，尚未实施**（代码处于改造前状态）。配套静态样机 `docs/ui-mockup/`（login / kb / chat 三页）为本规范的视觉基准。

---

## 1. 风格定义

| 维度 | 规则 |
| --- | --- |
| 背景 | **宇宙星空保留**（现有 cosmic-background / star-field / 流星层不动）——这是品牌资产 |
| 内容层 | 无卡片容器：面板类样式（glass-panel 等）统一拍平为透明区块 + 顶部 1px 分割线 |
| 分组方式 | ① 空白 ② 1px 分割线（`rgba(247,245,242,.1)`）③ 12px 大写小节标题 |
| 列表 | 行式：行高 ~54px，hover 整行微亮 + 左侧 2px 主色条 |
| 强调 | 琥珀金 `#e5a044`（hover `#ffc76d`）只给交互与当前态 |
| 容器 | 仅存：弹窗、聊天输入区、对话窗格分隔 |

**三禁**：禁卡片盒子（边框+底色+圆角+blur 的容器）、禁新内容区底色块、禁玻璃拟态。

---

## 2. 三种布局原语

1. **区块 Section**：小节标题（12px 大写灰字）+ 全宽内容；区块间 1px 分割线或 24px 空白。
2. **行 Row**：`[图标] 名称/描述 ──────── 元信息 状态 操作`；行高 54px，hover `rgba(247,245,242,.045)` + 左主色条。
3. **窗格 Pane**：仅对话类页面，左右窗格 1px 竖线分隔。

---

## 3. 设计令牌（global.css）

沿用深空令牌：`--text-primary #f7f5f2` / `--text-secondary #9a9896` / `--text-3 #8b90a0` / 主色 `#e5a044`（hover `#ffc76d`）/ 语义色 success `#7fdfa4`、warning `#f4b35a`、danger `#ff8a8a`；分割线 `rgba(247,245,242,.1)`；行悬停 `rgba(247,245,242,.045)`。

新增共享原语（已实现）：
- `.num-strip / .num-item`：页头数字条，mono 大数字（主色 hi）+ 灰标签，竖线分隔；
- `.row-list / .row-item / .row-icon / .row-name / .row-desc / .row-meta`：行列表原语；
- `.st-dot .ok/.warn/.idle`：状态点（绿/橙/灰）。

Element Plus 深色映射保持不变（EP 组件天然融入星空底）。

## 4. 组件规范

| 组件 | 规范 |
| --- | --- |
| 页头 | 22px 标题 + 13px 描述 + 右侧主操作按钮；下方 1px 分割线 |
| 数字条 | 页头下：mono 数字 + 灰标签，替代统计卡 |
| 行列表 | 见 §2.2；行尾常驻操作（⋯ 菜单或主按钮）；>50 行分页 |
| 状态 | 状态点 + 12px 语义色文字（可问答/解析中/待上传） |
| 弹窗 | 白字直角窗（继承深色 EP 弹窗），标题下 1px 分割线；危险操作红字置左 |
| 三态 | loading=骨架屏；empty=居中图标+一句话+主行动（现状已是标准）；error=红色行内文字+重试链接 |
| 消息（无气泡） | 每条消息 = 头像(26px) + 名字/时间小字头 + 正文直排；用户消息左侧 2px 主色条缩进；问答对之间 1px 分割线；操作行（朗读/大拇指）灰字链接式 |
| 追问建议 | 主色下划线文字链接横排（非胶囊盒） |
| 输入区 | 窗格底部固定，textarea 无边框，右下语音/发送 |

## 5. 页面改造要点（实施时逐页对照）

| 页面 | 改造要点 |
| --- | --- |
| 登录 `/login` | 去玻璃卡容器，表单直排星空，输入框下划线式 |
| 知识库 `/kb` | 统计卡→数字条；卡片网格→行列表（图标/名称/状态点/元信息/⋯菜单/去提问） |
| 智能体管理 `/agents` | 卡片网格→行列表（状态 tag 进标题行、技能 chips、右侧元信息、进入按钮） |
| AI 聊天 `/chat` | 消息无气泡（用户消息左 2px 主色条缩进）；回答操作行链接式 |
| 智能体对话 `/agent-tools` | 同聊天规范 |
| 技能管理 `/skills` | 三区拍平为小节纵排 |
| 用量统计 `/stats` | 统计卡→数字条；柱状图保底缩放；清除卡片渐变死代码 |
| 其余页面 | 经全局 glass-panel 拍平自动生效，后续按 §2 原语逐页精修 |
| 视觉展厅 ×8 | 独立暗色艺术页保留，不纳入 |
