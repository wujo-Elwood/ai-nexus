# 第二优先级企业能力设计

## 目标

补齐统一任务中心、检索调试台、RAG 评测中心、知识库处理策略和知识库统计面板。所有能力复用现有 Spring Boot、MyBatis、Vue 3 和 Element Plus，不改变现有上传、聊天、引用、版本管理和权限接口。

## 数据与接口

- `kb_knowledge_base` 增加知识库级 RAG 参数，缺省值沿用当前 `application.yml`。
- 新增 `kb_eval_case`、`kb_eval_run`、`kb_eval_run_item` 保存评测问题、运行快照和结果。
- 新增统一任务查询接口，任务数据从已有文件、上传、抽取、智能体和生图表中按用户权限聚合，不复制任务状态。
- 新增知识库统计接口，按知识库聚合文件、当前版本、切片、向量状态、质量状态和聊天引用数据。
- 新增检索诊断接口，返回查询改写、候选召回、融合重排和最终入选结果；正式聊天流程保持不变。

## 前端入口

- 知识库页面增加“策略与统计”区域，可保存参数、触发重索引、查看质量和趋势指标。
- 聊天页面增加“检索调试”入口，展示召回链路和参数调试结果。
- 侧边栏增加“任务中心”和“RAG 评测”入口；均受现有 JWT 和菜单权限保护。

## 可靠性

- 所有新接口执行当前用户和知识库权限校验。
- 评测运行失败保存失败状态和原因，不影响正式聊天。
- 策略参数进行范围校验，重索引操作只重新提交当前文件处理任务。
- 统计无数据时返回 0 和空列表，不返回空白页面或白色遮罩。

## 验收

- 后端单元测试覆盖参数校验、统计聚合、任务状态、评测指标和检索诊断。
- 前端生产构建通过，新增页面可从菜单访问。
- 旧上传、聊天、引用和现有测试全部回归通过。
