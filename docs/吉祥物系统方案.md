# 吉祥物系统方案 —— 从「菜单标记」到「系统宠物」

> 版本：v1（2026-10-03）· 方案稿，未实施
> 目标：吉祥物不再固定在侧栏菜单行上，而是住在整个系统里——会走、会跳、会对系统里发生的事情做出反应。

---

## 1. 概念定位

吉祥物是系统的**常驻小生物**：它有自己的位置、状态和脾气。用户每次操作，它都有可能回应；但它有自己的生活，不喧宾夺主。

一条总原则：**它的动作永远是对用户操作的回应，回应完回到待机**。打扰预算受控（见 §5）。

## 2. 动作目录

| 动作 | 触发时机 | 表现 |
| --- | --- | --- |
| **walk 走动** ★核心 | 切换菜单时 | 从旧激活行沿侧栏「走」到新激活行：小短腿交替、身体左右摇摆（rotate ±3°），距离越远走得越久（300–900ms 封顶） |
| **jump 跳跃** | 点击吉祥物 / 菜单行 | 已实现：二连跳 + 落地眨眼 |
| **idle 待机** | 无事发生 | 已实现：3.4s 周期小跳 + 眨眼 |
| **cheer 开心** | 任意操作成功（ElMessage.success） | 在消息气泡附近出现，原地蹦两下，头顶冒一个小星星 |
| **sad 沮丧** | 操作失败（ElMessage.error） | 趴下 1.5s，身体变灰，然后默默站起来 |
| **thinking 思考** | AI 流式回答中 | 蹲在输入框右缘，身体微倾，头顶冒三点思考气泡，回答结束回到待机 |
| **working 干活** | 文件上传 / 解析进行中 | 原地做俯卧撑（压扁-撑起循环） |
| **sleep 睡觉** | 60s 无任何输入 | 躺倒在侧栏底部，冒 Zzz 气泡；任意键鼠输入立刻惊醒跳一下 |
| **greet 打招呼** | 每个会话首次进入系统 | 从屏幕左缘走进来，走到菜单行站定（sessionStorage 记录，每次会话一次） |
| **speak 说话** | 偶发（2–5 分钟随机） | 冒一个对话气泡说一句话（如「今天已调用 38 次啦」），3s 后收回；可配置关闭 |
| **dance 舞蹈** | 点击吉祥物 | 已实现：二连跳 + 眨眼 |

## 3. 活动范围与位置系统

- **家**：侧栏当前激活菜单行（默认住址，所有待机动作都在这）。
- **外出**：只在两处短暂离开家——消息气泡附近（cheer/sad）和输入框旁（thinking），动作播完走回家。
- **绝不进入**：内容区正文上方长驻、登录页、弹窗内部。
- **z-index**：50（低于 Element Plus 弹窗/消息的 2000+，高于页面内容）。
- 移动方式：同为 `transform` 过渡；跨区域移动 = 先淡出、在目的地淡入走两步（避免斜穿整个屏幕挡内容）。

## 4. 技术架构

```
src/composables/useMascot.js     ← 全局单例状态机 + 事件总线
src/components/MascotActor.vue   ← 渲染（SVG 小家伙 + 气泡），fixed 定位
src/utils/mascotActions.js       ← 动作注册表（keyframes/时长/优先级）
```

- **状态机**：`idle / walking / cheering / sad / thinking / sleeping / hidden`；高优先级动作可打断低优先级（sad > cheer > thinking > idle）。
- **菜单联动**：MainLayout watch 路由 → `mascot.walkTo(新激活行坐标)`（替代现在的瞬移）。
- **全局消息钩子**：main.js 里包装一次 `ElMessage.success / error`，成功/失败自动广播给吉祥物——**业务代码零改动**。
- **AI 思考联动**：ChatView / AgentToolView / DataAnalysis 把 streaming 状态写入 `mascot.thinking(bool)`（三处各一行）。
- **睡眠计时**：window 的 mousemove/keydown/scroll 节流监听，60s 无输入入睡。
- 现有侧栏吉祥物代码整体迁入 MascotActor，MainLayout 只保留挂载与路由联动。

## 5. 防打扰规则

1. 主动作（cheer/sad/walk）每分钟最多 4 次，随机延迟 ±400ms 避免机械感；
2. walk 只发生在侧栏内，不横穿内容区；
3. `prefers-reduced-motion` 下全部退化为静帧；
4. 用户菜单加「吉祥物：开/关」开关（存 localStorage）；
5. 页面切后台（document.hidden）暂停所有动画。

## 6. 分期实施

| 期 | 内容 | 预估 |
| --- | --- | --- |
| **P1 核心** | 组件抽离 + walk 菜单联动 + cheer/sad（消息钩子）+ sleep | 约半天 |
| **P2 陪伴** | thinking（三个 AI 对话页）+ greet 开场 + speak 气泡 + 系统开关 | 2–3 小时 |
| **P3 彩蛋** | 可拖拽定居任意位置 + 页面专属彩蛋（如全部任务完成时绕屏跑一圈） | 按需 |

## 7. 验收清单

- [ ] 切换菜单时吉祥物走过去而非瞬移；
- [ ] 任意保存/删除操作成功或失败时，它有对应反应且不影响操作；
- [ ] 60s 不动它睡着，动一下鼠标它惊醒；
- [ ] AI 回答期间它在输入框旁思考；
- [ ] 弹窗打开时它永远在弹窗下面，不挡任何点击；
- [ ] 设置里可以整体关闭它；
- [ ] 星空背景与登录页不受影响。
