## 1. 用户反馈的翻译（模糊词 → 可观察决定）

「一眼 AI 做的那种卡片式」翻译成本轮的设计禁令：

| AI 卡片风的特征（禁用） | 本轮替代手段 |
| --- | --- |
| 万物皆圆角卡片 + 投影 + 浮层 | 内容直接坐在背景上，用**通栏横线**和**严格列网格**分区 |
| 紫/蓝/粉渐变光晕、玻璃拟态、发光 | **零渐变、零 blur、零发光**；光只能来自星空本身 |
| 每个模块一个彩色渐变徽章/胶囊 | **无图标**，用编号（01/02…）、大写小标、方括号标签 |
| 居中友好的营销语气 | 仪表语气克制、信息密度高、像专业工具 |

同时保留 v1→v2 一路验证过的有效资产：状态彩点语义、真实数据结构、页面信息层级。

## 2. 品类与标杆（本轮重拆）

品类不变：AI 工作台。本轮拆的新标杆（都不是卡片式产品）：

- **天体图年鉴（Uranographia 类星图集）**：坐标网格、图版编号、目录点线、图例集中在页缘。取：索引编号体系、点线引导、图幅头的读数带。
- **机场出发信息板**：全部信息以「行 × 列」组织，状态用文字标签，不藏进卡片。取：通栏行列表、hover 反白的状态切换。
- **书籍边注 / 目录页**：主角是巨大标题，元数据退到边距。取：巨字行、边注栏。

三个方向的共同底线：**信息不装进容器**——用排版本身（字号、字重、留白、横线、对齐）分层。

### 差异检验

- 骨架：A 顶部图幅头 / B 左索引轨 / C 单列巨字——互不相同。
- 字体：A 衬线展示 / B 全 mono / C 巨号黑体——互不相同。
- 色彩：A 骨白+朱砂 / B 白+绿+琥珀 / C 纯黑白——色相家族与数量都不同。
- 主视觉：A 点线目录 + 坐标带 / B 反白行 + 方括号标签 / C 负片巨字——互不相同。
- 三者全部无卡片、无渐变、无发光、无侧栏（A/C）或极简轨（B），共同满足反 AI 卡片风禁令。

### 选定：方向 A，理由

1. **反 AI 感最彻底**：衬线大字 + 编号 + 点线 + 通栏横线是「人做的书」的气质，与 AI 生成的圆角渐变卡完全相反；B 的 mono 看板与 v1 仪表血统最近，C 的黑白巨字对工具效率牺牲最大。
2. **题材自洽**：产品管的是「知识库/星图」，图集语法直接来自产品题材，不是贴皮。
3. **效率保得住**：横线表格是信息密度最高的形式，编号导航一屏可见，高频操作（进入/提问/管理）都在行内。
4. **背景不变的最优解**：内容无容器直接坐在星空上，比 v2 的玻璃更彻底地把背景让给画面。

## 4. 方向 A 设计语言规范

### 4.1 设计原则

1. **无容器**：任何信息块都不加底色盒；分区只靠 1px 横线（rgba(236,233,225,.10)）、列对齐与留白。
2. **编号即图标**：全站无图标。导航、列表、按钮层级一律用编号 + 大写小标。
3. **一种信号色**：朱砂红只许三处——当前项标记、主动作按钮、告警状态。其余一律骨白/灰阶。
4. **数字必 mono**：所有读数、日期、占比用等宽字体 + tabular，右对齐。

### 4.2 设计令牌

```css
:root {
  --ink-1: #ece9e1;            /* 骨白主文字 */
  --ink-2: #9a9890;            /* 次级 */
  --ink-3: #5d5b55;            /* 弱化/读数标签 */
  --signal: #ff6b57;           /* 朱砂信号色（当前项/主动作/告警） */
  --rule: rgba(236, 233, 225, 0.10);   /* 1px 横线 */
  --rule-strong: rgba(236, 233, 225, 0.22);
  --row-hover: rgba(236, 233, 225, 0.04);
  --font-display: "Noto Serif SC", "Source Han Serif SC", "Songti SC", SimSun, serif;
  --font-sans: "Noto Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
  --font-mono: "JetBrains Mono", Consolas, monospace;
  --motion: cubic-bezier(0.32, 0.72, 0.24, 1);
}
```

### 4.3 组件语法

- **图幅头**：左侧衬线页标题（34px）+ 一行 12.5px 描述；右侧 mono 读数带（`库 04 · 文件 60 · 可问答 50`，等宽右对齐，字距 0.08em）；头下一条 1px 通栏横线。
- **编号导航**：页眉横排 `01 知识库  02 对话  03 生图 …`，mono 编号 + 无衬线词；当前项编号变朱砂 + 下方 2px 短线。
- **目录行（列表原语）**：`编号(11px mono 灰) | 名称(衬线 20px) | 描述(13px 灰) ……点线…… | 读数(mono 右对齐) | 状态词`。点线用 `border-bottom: 1px dotted` 的伪元素或字符省略；hover 行背景 +4% 白。
- **状态词**：`● 可问答`（点为骨白）/ `◐ 解析中` / `× 失败`，仅形状区分，不引入彩色；告警才允许朱砂。
- **按钮**：次级 = 方角 1px 描边骨白字，hover 描边变亮；主 = 朱砂实底方角黑字；均无圆角、无投影。
- **读数列**：页缘或行右的 mono 数字组，标签 10px 大写字距 0.18em。
- **表格**：无底色通栏，只有横线；表头 10px 大写灰。
- **对话**：手稿式直排；用户条目带左缘 2px 朱砂短线；AI 回答直排骨白；引用以「注 N」编号挂行尾，页面底部注释区展开（书页脚注语法）。
- **弹窗**：直角、1px 骨白描边、黑底、无投影模糊。

### 4.4 三处基本动效

1. **主操作**：主按钮按下无位移，仅颜色加深一档（印刷按压感）+ 150ms。
2. **状态切换**：导航当前项的朱砂短线 160ms 从旧项滑到新项；行选中同语法。
3. **入场**：页面标题与坐标带自左向右 0.94→1 透明度渐显（240ms，一次性）；无扫光无浮动。

### 4.5 页面级要点（示例内容与 v2 对比页一致）

| 页面 | 图集语法 |
| --- | --- |
| 知识库 | 图幅头（读数带：库/文件/可问答）→ 图版目录表（编号+衬线名+点线+读数+状态词）→ 行尾动作「提问 →」「管理 →」 |
| AI 聊天 | 左栏为「对话索引」（编号 + 标题 + 日期），主区为手稿直排 + 脚注式引用 |
| 智能体 | 图版目录表；技能清单为行内 mono 词表（空格分隔，无 chip 盒） |
| 用量统计 | 通栏数字表 + 纯文本条形（▮▮▮ 字符或 1px 线段），无图表卡 |

### 4.6 与 v2 的关系

- 若选定 A：`global.css` 令牌层按 4.2 重写，MainLayout 去侧栏改图幅头（星空背景与登录页仍不动），视图层移除卡片/圆角/渐变类。
- v2 的「数据可视化单色化、状态语义、页头第一屏内容」等评审结论继续有效。

### 5.1 全量页化时新增/确认的语法（对第 4 节的补充）

- **行式表单**（`.form-line`）：标签左 + mono 英文小标，控件右，1px 横线分行——替代所有弹窗/设置类表单的卡片容器。
- **目录表**（`.table`）：全站唯一表格原语；表头 mono 9.5px 大写宽字距，行 hover +4% 白，操作列文字链接。
- **文字开关**（`.sw`）：[ON]/[OFF]/[启用]/[隐藏] mono 词，替代一切开关组件的彩色填充。
- **细线条形**（`.linebar`）：进度/用量/置信度的唯一表达，告警态用朱砂。
- **步骤日志**（`.steps`）：智能体/数据分析的工具调用过程 = mono 航行日志行（STEP N · 工具(参数) → 结果 · OK · 耗时）。
- **通栏读数列**（`.ledger`）：四栏大数字 + 细竖线分隔，替代统计卡。
- **虚线上传条**（`.ghost-upload`）：文件/抽取的上传区，通栏虚线，非面板。
- **图版编号体系**：主功能 I–XIV，子页用 ·B/·C 后缀（I·B 文件、II·B 智能体对话、XIV·B 修改密码）。
